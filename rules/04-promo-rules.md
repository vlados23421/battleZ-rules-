# 🎫 Правила промокодов

*Версия 1.0 | Последнее обновление: 17 августа 2026*

---

## 📌 1. Что такое промокод?

Уникальный код для получения бонусов.

---

## 📌 2. Типы промокодов

| Тип | Бонус |
|-----|-------|
| ⭐ Звёзды | +10-100 ⭐ |
| 💰 Золото | +50-500 💰 |
| 💳 Скидка | 10-50% |
| 👑 Премиум | 7-30 дней |

---

## 📌 3. Правила использования

- Активация: `/promo_use КОД` в боте
- Один промокод = один раз
- Срок действия: 7-30 дней

---

## 📌 4. Ответственность

- Администрация не восстанавливает утерянные промокоды
- Администрация может отозвать промокод при нарушениях
